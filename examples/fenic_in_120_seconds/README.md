## 🎬 Demo Format

Each notebook follows a consistent **2-minute demonstration** structure:

1. **⚡ Quick Setup** - One-cell installation and API configuration
2. **📊 Real Data** - Synthetic datasets that mirror actual business challenges  
3. **🧠 AI Magic** - Fenic semantic operations solving the problem
4. **📈 Business Impact** - Quantified results and value propositions

## 🛠️ Technical Features Demonstrated

- **Semantic Operations**: `classify`, `extract`, `map`, `join`, `group_by`, `sim_join`
- **Multi-Provider LLMs**: OpenAI integration with rate limiting and caching
- **Structured Extraction**: Pydantic schemas for reliable data parsing
- **Fuzzy Matching**: Built-in text similarity algorithms with AI verification
- **Performance Optimization**: Smart caching to prevent redundant LLM calls

No local setup required - everything runs in your browser!
